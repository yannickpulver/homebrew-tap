# homebrew-tap

Homebrew tap for Yannick Pulver's apps.

## Install

```sh
brew tap yannickpulver/tap
```

## Apps

```sh
brew install --cask raw-viewer
brew install --cask copier
brew install --cask slides
```

## CLI tools

```sh
brew install yannickpulver/tap/bonbox
brew install yannickpulver/tap/reviewer
brew install yannickpulver/tap/budget
brew install yannickpulver/tap/make-android-keystore
```

## Update

```sh
brew update
brew upgrade --cask raw-viewer copier slides
```
